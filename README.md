# Makara Thina — Modern React Portfolio

This is a multi-page React portfolio inspired by the dark modern portfolio screenshot you provided.

Pages:
- Home
- Skills
- Projects
- About
- Contact

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Main files

- `src/App.jsx` — pages, navigation and content
- `src/style.css` — full design
- `public/profile.jpg` — profile image
